# Finance & Investment Analyst Internship - CodeAlpha

This repository contains the finance and investment analysis tasks completed during the **CodeAlpha Internship Program**.

## Project 1: Stock Analysis Report
- Selected 3 prominent US / Indian stocks for fundamental and technical evaluation.
- Analyzed price trends, P/E ratios, market capitalization, key financial performance indicators, and recent market news.
- Compiled a comprehensive report featuring data visualizations, performance charts, and strategic investment conclusions.

## Project 2: Cryptocurrency Portfolio Analysis
- Conducted performance and risk analysis for 3 major cryptocurrencies (e.g., BTC, ETH, SOL) over a 12-month period.
- Calculated key metrics including historical returns, volatility, and risk-adjusted performance.
- Developed an interactive Google Sheet model along with an insights and recommendations report.

## Project 3: Investment Portfolio Creation
- Constructed a hypothetical investment portfolio with an initial capital of ₹1,000,000.
- Implemented strategic asset allocation across stocks, ETFs, and cryptocurrencies with clear investment rationale.
- Modeled portfolio performance in a Google Sheet accompanied by an explanatory report detailing risk tolerance and strategy.

## Project 4: Mini Project – Market Research & Investment Strategy
- Authored a research report evaluating market trends, investment strategies, and sector outlooks.
- Compared structural trends between stock markets and cryptocurrency markets.
- Formulated risk management frameworks and analyzed future growth outlooks for selected investment sectors with supporting charts and references.

### Folder Structure

- `project2/`: Contains the 12-month cryptocurrency performance data, risk metrics, and reports.
- `project3/`: Contains the ₹1,000,000 asset allocation models, spreadsheets, and strategy documents.
